# 2026-07 SCRM 无效客资审批流程

## 批次信息

- 批次 ID：`2026-07-scrm-invalid-approval-flow`
- 所属产品：SCRM
- 涉及模块：潜客管理
- 涉及页面：门店客户

## 概述

本批次覆盖门店客户列表字段调整（删除实际到店/成交状态、调整字段顺序、新增首笔成交金额）以及无效客资申请、审核与详情闭环。

## 闭环

### 闭环一：列表字段调整

- 删除「实际到店状态」「实际成交状态」
- 「预约到店时间」移至最新分配时间与是否到店之间
- 新增「首笔成交金额」
- 「无效客资状态」统一更名为「无效审批状态」
- 最终 51 列

### 闭环二：审批流程

- 本批次不区分账号身份，操作入口只根据无效审批状态决定
- null：显示「标记无效客资」
- pending：显示「审核无效标注」
- approved：不显示无效审批相关操作
- rejected：显示「标记无效客资」
- 详情仅通过点击非空的「无效审批状态」标签打开
- 操作菜单中不存在「查看详情」和「重新申请」
