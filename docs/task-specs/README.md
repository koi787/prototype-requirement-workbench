# 开发任务单

此目录用于保存后续经产品经理确认的开发任务单。

## 协作流程

1. 产品经理与 GPT 澄清需求，由 GPT 判断任务模式并输出需求确认卡。
2. Codex 根据需求确认卡创建或维护任务单。
3. Claude + DeepSeek V4 按任务单开发并完成开发侧自检。
4. Claude 首版完成后，产品经理先进行真实页面验收。
5. 产品经理确认进入 Review 后，Codex 执行一次正式 Review、必要时一次限定复审，并完成最终验证和经确认的 Git 操作。
6. 产品经理负责最终交付验收。

## 任务单规范

- 使用稳定递增编号和清晰英文文件名（如 `0006-new-feature.md`）。
- 任务单不得包含公司资料、真实凭据、本机绝对路径或内部截图。
- 历史任务单只记录本仓库启用后的新任务，不补录历史仓库任务正文。
- 任务单必须写明任务模式、业务目标、修改范围、明确不做、业务规则、UI 等级和验收标准。
- 后续 Claude 和 Codex 的入口提示只需引用 `AGENTS.md` 和当前任务单，不重复粘贴完整治理规则。
- 每份正式任务单均默认继承根目录 `AGENTS.md` 的“任务完成通知”规则，并包含简短的“任务完成通知”章节。
- Codex 使用用户级 `notify` Hook，不得在任务单中要求 Codex 手动执行通知命令或申请通知审批。
- Claude Code 继续按 `AGENTS.md` 的手动通知规则执行，并把通知作为最后一个工具操作。
- 其他代理优先使用自身运行时 Hook；没有 Hook 时才采用手动通知。
- 自动 Hook 和手动脚本不得同时使用，每个任务最多发送一次通知。
- 通知失败不得改变任务结论。

## 任务模式

### M1 快速改动模式

- 适用于边界明确的小改动，目标当天完成。
- 使用一页任务单，执行相关最小验证和最终完整验证。

### M2 标准业务页面模式

- 适用于业务页面及关联状态、交互，目标 1—2 个工作日。
- 最多两个开发闭环；产品经理完成真实页面验收后，Codex 才开始正式 Review。

### M3 基础设施模式

- 适用于 Schema、通用组件、锚点、页面壳和公共能力。
- 单独排期，按跨页面影响执行基础设施级 Review。

### M3-S 轻量通用修复

- 适用于范围明确的小型通用修复。
- 不使用重型基础设施 Review，不得扩大为架构重构。

## UI 验收等级

- A 级：业务结构一致，默认使用。
- B 级：关键视觉风格一致，M2 关键区域可明确采用。
- C 级：像素级接近，仅在产品经理明确要求时采用。

未要求 C 级时，轻微字号、间距、颜色、阴影和像素位置差异不得阻塞交付。

## Review 流程

Review 输出固定分为“阻塞问题、建议优化、已知债务”。仅功能错误、规则错误、关键交互不可用、明显回归、安全问题、假测试和验证或构建失败可以阻塞。

每个任务最多一次正式 Review 和一次限定复审。限定复审只检查原阻塞项及明显回归，不重新扩张到新的低价值问题。

每个开发小闭环只执行相关最小验证；最终交付前统一执行：

```bash
pnpm lint
pnpm typecheck
pnpm test
pnpm build
pnpm build-storybook
```

## 任务完成通知要求

Codex 任务只引用用户级 `notify` Hook。Codex 完成任务后正常输出最终报告并结束本轮；`agent-turn-complete` 事件由运行时自动触发通知。任务单不得要求 Codex 手动执行 `osascript` 或 `afplay`，也不得要求通知命令成为 Codex 的最后一个工具调用。

Claude Code 任务继续引用根目录 `AGENTS.md` 的手动通知规则：完成全部操作、验证、Todo 和报告整理后，最后主动发送一次通知，通知后不再调用工具。

任务单不得重复粘贴完整通知脚本，也不得同时要求自动 Hook 和手动脚本。

以后由 Codex 创建的每一份正式任务单，均应包含以下章节：

````markdown
## 任务完成通知

本任务完成后，必须按照项目根目录 `AGENTS.md` 的“任务完成通知”规则执行：

- Codex 使用用户级 `notify` Hook 自动通知，不手动执行通知命令；
- Claude Code 使用手动通知，并将通知作为最后一个工具操作；
- 其他代理优先使用自身运行时 Hook，没有 Hook 时才手动通知；
- 不得同时使用两种机制，不得重复通知；
- 通知失败不得影响任务结论。
````

任务单只引用项目级规则，不重复维护 Shell 或 AppleScript 完整通知脚本。`AGENTS.md` 规则始终有效，即使某份任务单漏写通知章节。只有产品经理明确要求“本轮静默执行”时，才可以不发送通知。

## 相关入口

- 工程治理规范：项目根目录 `AGENTS.md`
- 需求数据结构：`REQUIREMENT_SCHEMA.md`
- 项目模块边界：`PROJECT_STRUCTURE.md`
