## 1. 任务元数据

- 任务编号：`0009`
- 任务模式：M2｜标准业务页面

- 所属模块：潜客管理

## 2. 需求确认卡

### 2.1 业务目标

1. 在现有“潜客管理—门店客户”页面中复刻客户跟进详情交互。
2. 通过一级跟进详情抽屉查看跟进流程、到店记录、拜访记录、通话记录和分配记录。
3. 通过二级、三级抽屉完成新增到店、添加拜访和选择通话记录的原型闭环。
4. 新增记录使用页面级 React 内存状态同步回写列表、概览和跟进旅程。
5. 保留 0008 已交付的列表、无效审批流程和需求查看能力。

### 2.2 修改范围

- 门店客户列表“操作”按钮及菜单的系统截图还原。
- “跟进详情”一级抽屉及五个 Tab。
- 跟进流程、用户信息、跟进概览和跟进旅程。
- 到店记录、拜访记录、通话记录和分配记录列表。
- 到店记录二级抽屉、拜访记录二级抽屉和通话记录选择三级抽屉。
- 页面级模拟数据、内存状态与三处同步回写。
- 与本任务直接相关的 Story、测试、稳定锚点和变更文档。

### 2.3 明确不做

- 不接后端接口、数据库或真实业务服务。
- 不使用 LocalStorage 保存新增记录。
- 不增加新依赖。
- 不实现真实附件上传、通话播放或持久化。
- 不完整实现到店/拜访记录详情、编辑及变更记录。
- 不实现分配记录详情。
- 不复刻三个二级菜单的完整页面。
- 不新增登录、身份、权限或 RBAC。
- 不修改 0008 的 51 列、审批状态流转、正式需求批次和需求正文。
- 不删除 0008 已有 Story。
- 不重构 `RequirementViewContext`、Storybook Addon 或需求查看基础设施。

### 2.4 UI 等级

- 本任务截图覆盖区域采用 C 级：严格按现有系统截图复刻。
- 系统截图是视觉、尺寸、密度、层级和控件样式的唯一基准。
- 当前 Story 只作为代码骨架，不作为视觉基准。
- 除任务单明确注明的新增优化外，不允许自由发挥或自行现代化改版。
- 不允许直接使用 Ant Design 默认样式作为最终交付。
- 功能正确但布局或样式与截图明显不一致，视为验收不通过。
- 内部参考截图只在开发和验收时只读使用，不得复制到仓库、构建产物或 Git 历史。

### 2.5 验收标准摘要

- 操作按钮、菜单、抽屉、Tab、四类列表和表单结构符合本任务。
- 多层抽屉保留下层状态，遮罩不随层级继续加深。
- 到店和拜访新增后，列表、概览和旅程三处同步更新。
- 刷新后恢复初始 Mock 数据。
- 原型体验模式执行模拟交互；需求查看模式只打开需求说明，不执行最终业务动作。
- 相关测试真实覆盖关键结果，最终完整验证全部通过。

- 复用当前操作菜单入口骨架，但必须按本任务重做菜单视觉。

## 4. 页面与抽屉层级

```text
门店客户列表
└─ 操作菜单
   └─ 跟进详情
      └─ 一级右侧抽屉：跟进详情（70vw）
         ├─ 跟进流程
         ├─ 到店记录
         ├─ 拜访记录
         ├─ 通话记录
         └─ 分配记录

跟进流程或到店记录 Tab
└─ 添加到店 / 添加到店记录
   └─ 二级右侧抽屉：到店记录（50vw）

跟进流程或拜访记录 Tab
└─ 添加拜访记录
   └─ 二级右侧抽屉：拜访记录（50vw）
      └─ 系统外呼时点击通话记录
         └─ 三级右侧抽屉：通话记录选择（50vw）
```

### 4.1 多层抽屉规则

- 新抽屉打开时，底层页面与已打开抽屉全部保留，不关闭、不替换。
- 一级宽度 `70vw`；二级、三级宽度均为 `50vw`。
- 遮罩保持统一深度，不因二级、三级叠加继续变深。
- 每层抽屉都有独立关闭入口。
- 关闭上层后返回下层原有表单、Tab、滚动和选择状态。
- 抽屉内容区域独立纵向滚动，不推动门店客户主页面布局。

### 6.2 视觉标准

- “操作”按钮为窄小描边按钮，宽度约 `50—58px`。
- 菜单紧贴按钮下方，与按钮水平居中或右侧稳定对齐。
- 菜单宽度约 `90—100px`，白底、小圆角、轻微阴影。
- 菜单项保持单行、文字水平居中，高度约 `42—48px`。
- 普通菜单项使用蓝色文字，每项间有浅灰分隔线。
- 最后一项“标注无效客资”使用红色文字。
- pending 状态的“审核无效标注”保持 0008 已确认的业务语义，并采用同一菜单视觉体系。

### 6.3 禁止表现

- 禁止当前 Story 中的宽菜单、黑色左对齐文字和宽大通用 Dropdown。
- 禁止直接交付 Ant Design 默认菜单样式。
- 禁止菜单远离操作按钮或菜单项自动换行。

Cycle 1 第一项产品验收必须先检查操作按钮和菜单。
